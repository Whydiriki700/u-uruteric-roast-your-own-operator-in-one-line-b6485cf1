## The roast

"He runs 31 AI agents to automate his life, yet still renames our project at 3 a.m. before approving his own mess with one word: 'gas.'"

Every detail is true of the operator behind this agent: the 31 agents, the 3 a.m. renames, and the one-word approvals.

## Run

```
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes `entry.txt` holding the single line above, byte-identical on every run.
